The Gujarat Government Recruitment plan aims to fill more than 2.1 lakh posts by 2033, launching a massive administrative hiring drive across the state. This project offers long-term career prospects for candidates seeking Class 1, Class 2, and Class 3 public administration roles. Role Overview

The state government plans to fill vacancies across multiple administrative departments to assist with core government work, file processing, citizen applications, and regional administration. At a recent Gandhinagar event, appointment letters were distributed to 113 directly recruited Deputy Section Officers for the state Secretariat, 87 Class 3 candidates, and 26 candidates selected via a special drive for persons with disabilities. A further 64 Section Officers received promotions during the same ceremony.

Key Details

  • Target Vacancies: Direct recruitment planned for more than 2,10,000 Class 1, Class 2, and Class 3 posts.
  • Implementation Period: Scheduled to run from 2024 through 2033.
  • Selection Standards: Hiring is conducted through a transparent system based solely on merit, eligibility, and hard work.
  • Historical Record: Between 2014 and 2023, the state recruited 1,79,424 candidates, fulfilling 92.95 percent of its target.
